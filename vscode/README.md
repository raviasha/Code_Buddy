# Code Buddy - VS Code Extension

This folder contains the latest VS Code extension build for Code Buddy.

## Installation

1. Download the `.vsix` file from this folder
2. Open VS Code
3. Go to Extensions (Cmd+Shift+X on Mac)
4. Click the "..." menu and select "Install from VSIX..."
5. Select the downloaded `.vsix` file

## Files

All `.vsix` files in this folder are ready to download and install
